## Giới hạn phạm vi có chủ đích

Rubric/rule/LLM evaluator tự động chưa được build và **chủ đích không nằm trong UAT T-023**. Đây không phải thiếu sót của báo cáo. UAT dùng một rubric thủ công gồm một criterion trọng số 100%. Một finding cùng evidence anchor được seed làm fixture sau khi Document IR hoàn tất, chỉ để nghiệm thu PDF.js viewer, liên kết finding-marker, review, approve và publish; không dùng fixture này làm bằng chứng evaluator hoạt động.

Không thêm feature để lấp các màn hình chưa có. Sau blocker đầu tiên, quyết định phạm vi là tiếp tục các luồng UI đang chạy được, ghi fail cho phần chưa build.

## Phân loại finding

### Đã sửa

- **BLOCKER — Compose thiếu frontend:** `docker-compose.yml` trước T-023 chỉ khởi chạy backend dependencies. `ab6c140` thêm service frontend. Release hardening `ecccd8a` chuyển image sang Vite production build do Caddy phục vụ, proxy `/api` nội bộ tới `http://api:8000`, bind frontend/API host port vào loopback và thêm frontend typecheck/build/image CI.
- **MAJOR — result cũ biến mất khi có resubmit chưa publish:** sửa selection query để giữ result mới nhất từng publish hiển thị, không phá semantics unpublish; disable review request trên result cũ khi có document version mới hơn. Commits: `4a7e902`, `a6b928e`.
- **BLOCKER — Admin operations:** DOC-33 nối Admin dashboard, user create/update, job monitoring/retry, audit và queue force-release vào product UI; bổ sung create-user API cùng optimistic concurrency. Commits: `e9b9cac`, `9559a54`.
- **BLOCKER — Teacher review response và Student notification/read:** DOC-32 nối Teacher/Admin appeals, Student request detail và notification center polling vào API thật. Release review bổ sung notification history pagination, cache invalidation và URL history đúng. Commits: `55b4845`, `23c43d3`, `0abcdf7`, `28b578b`, `a6b928e`.
